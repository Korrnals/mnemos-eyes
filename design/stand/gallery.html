Галерея стенд

Живая витрина канона: палитра, слово, плотность, состояния, импульсы

Кора Ирис Слово Плотность Состояния Иконки Импульсы

Кора

Лестница глубины: чем глубже поверхность, тем темнее слой. Чистый #000 запрещён; в светлой теме лестница инвертируется по свету.

Ирис

Пять смысловых цветов. Свет = данные: свечение законно только у активного узла, фокуса-зрачка и live-пилюли — не больше двух источников в кадре.

свет = данные live активный узел

Слово

Inter — интерфейс, Lora — свиток, JetBrains Mono — числа и id. Имена токенов шкалы заморожены.

Плотность

Операционная (32px строка) и созерцательная (56px). Переключатель двигает реальные строки.

M-219Словарь импульсов0.94
M-215Heartbeat-контракт0.95
M-204Решение по пейрингу0.88
M-177Выбор шрифтов0.90

Состояния

Матрица спеки 05: каждый интерактив несёт hover / focus / active / disabled / loading / error / empty. Информация никогда не только цветом.

Иконки

Lucide-стиль: stroke 1.5px, размеры 16 / 20 / 24. Запреты — с пояснением.

канон

Импульсы

Словарь синапс-импульсов: импульс бежит по ребру только на реальное событие, затухание ≤240 мс. Цвет дублируется текстом в ленте.
