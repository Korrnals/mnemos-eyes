# 06 — Motion-канон «Живая кора»

> Status: **v2.0, 2026-09-25**. Два закона:
> **(1) свет и движение = данные, не декор; (2) анимация никогда не стоит между
> пользователем и данными.** Все значения — токены из `02-TOKENS.md`.

## 1. Длительности (лестница)

| Токен | Значение | Окно ресерча | Что |
| --- | --- | --- | --- |
| `--duration-instant` | 80ms | — | тинты состояний, hover-фон, чипы |
| `--duration-fast` | 150ms | 120–180 | микровзаимодействия: кнопки, чипы, фокус-ринг |
| `--duration-normal` | 250ms | 240–400 | раскрытия: дровер, тулбар bulk, зрачок поиска |
| `--duration-slow` | 400ms | ≤500 max | крупные переходы: всплытие ленты, окна стола |
| `--duration-impulse` | 240ms | ≤240 | жизнь синапс-импульса |
| `--duration-iris` | 5000ms | 4–6s | амбиентное дыхание (одно на всё) |
| `--duration-stagger` | 40ms | 20–40 | шаг каскада списков (макс 8 в цепочке) |

Правила: всё, что длиннее 400ms — только ambient и canvas-физика; ничего
интерактивного. Переходы маршрутов ≤500ms, `opacity`-доминантные (без layout shift).

## 2. Easing (роли, не вкусовщина)

| Токен | Кривая | Роль |
| --- | --- | --- |
| `--ease-enter` | `cubic-bezier(0.16, 1, 0.3, 1)` | вход: всплытие, раскрытие, появление |
| `--ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | выход: закрытие, уход из списка |
| `--ease-out` | `cubic-bezier(0, 0, 0.2, 1)` | мягкий сдвиг, тултипы |
| `--ease-in-out` | `cubic-bezier(0.4, 0, 0.2, 1)` | симметричные смены (режим, тема) |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | ТОЛЬКО drag/reorder (канбан, окна) |
| `--ease-breath` | `cubic-bezier(0.45, 0.05, 0.55, 0.95)` | дыхание колодца |

Правило парности: элемент, входящий с `--ease-enter`, уходит с `--ease-exit`.

## 3. Stagger (каскады)

- Шаг `--duration-stagger` 40ms; максимум **8** анимаций в цепочке, остальное —
  мгновенно (результаты поиска, лента).
- Каскад только на вход (всплытие из глубины: opacity 0→1 + translateY 8→0,
  `--ease-enter`, `--duration-normal`); на выход — мгновенно или общим фейдом.
- Каскад прерывается любым вводом пользователя (новый запрос = новый каскад).

## 4. Ambient (дыхание)

- Единственное амбиентное движение шелла — микродыхание бренд-ириса в топбаре:
  период `--duration-iris` 5s, амплитуда ≤0.06 opacity, `--ease-breath`.
- Canvas-колодец: собственное медленное течение (дрейф узлов ≤4px/сек) —
  считается **вторым** ambient и живёт только на «Обзоре»; на остальных
  страницах канваса нет.
- Duty cycle: амбиентные слои занимают ≤20% площади вьюпорта; **никогда под
  текстом** (wash страт — статичен, не анимируется).
- При любом взаимодействии (фокус ввода, открытие палитры) амбиент
  приостанавливается (`animation-play-state: paused`), возобновляется через 10s
  бездействия.

## 5. Синапс-пульс — словарь (ядро уникальности)

Импульс — **бегущая точка по ребру/линии**, только на реальное событие, затухание
`--duration-impulse` ≤240ms, максимум 1 импульс на ребро одновременно, глобально
≤6 одновременных.

| Событие | Цвет | Где дублируется |
| --- | --- | --- |
| recall-попадание (поиск, ссылка в свитке, выбор) | `--synapse-recall` (ирис) | строка живой ленты, точка события |
| запись агента (write, отчёт) | `--synapse-write` (золото) | лента, узел агента, файл в проводнике |
| ошибка (SSE-разрыв, failed assignment) | `--synapse-error` (красный) | пилюля статуса, лента |
| нет события | нет импульса. Никогда. | — |

Правило честности: импульс без события в ленте — блокер ревью (фейковая жизнь —
анти-клише №1). Цвет импульса всегда дублируется текстовым/точечным сигналом
вне канваса (WCAG 1.4.1).

## 6. Бюджет glow

- Blur ≤24px, opacity слоя ≤0.35, ≤2 источников в вьюпорте.
- Законные источники: активный узел канваса, focus-зрачок поиска, live-пилюля.
- Всё остальное — тень, не glow (лестница `--shadow-*`).
- Glow не анимируется сам по себе: появляется/уходит с состоянием
  (`--duration-fast`).

## 7. Reduced-motion (OS + пользовательский тумблер)

Переключатели: `prefers-reduced-motion: reduce` ИЛИ `[data-motion="reduced"]`
(настройка в «Настройках» — зеркало, значения идентичны).

| Было | Стало |
| --- | --- |
| синапс-импульс | статический тинт ребра цветом события на 1.5s |
| амбиент-дыхание, течение канваса | выключено; канвас — статичная композиция |
| каскады списков | мгновенное появление |
| сечатая печать терминала | мгновенный вывод |
| все transition | только opacity, ≤80ms (`--duration-fast`) |

Focus-ринги, hover-тиинты и glow (статический) сохраняются — это не движение.

## 8. Производительность канваса (контракт для frontend)

- Canvas 2D без зависимостей: предрендер радиального glow-спрайта в offscreen
  canvas + `globalCompositeOperation: 'lighter'`.
- DPR cap 2; пауза по `document.hidden`; ≤300 узлов; цель 60fps на слабом железе.
- Деградация: <50fps → 150 узлов, glow-спрайты off; предупреждение в консоли стенда.
- Полный «Атлас» (1k+ узлов, sigma.js v3) — будущая фаза, в стенд не входит.
- SVG — только стационарные мини-карты (без анимации).
- rAF-цикл один на страницу; всё анимируемое вне CSS живёт в нём.
