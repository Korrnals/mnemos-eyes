# 04 — Экраны стенда (8 спек)

> Status: **v2.0, 2026-09-25**. Стенд: vanilla HTML/CSS/JS без сборки, тёмная тема
> default, светлая — в «Галерее», RU-копирайт и aria-атрибуты, reduced-motion
> обязателен. Один shell на все экраны (см. `03-IA-NAVIGATION.md`). Композиции
> экранов **намеренно разные** — no identical-card SaaS kit.

Общие правила для всех экранов:
- Плотность: операционные поверхности — `--text-data`, строки 32–40px; созерцательные
  (списки памяти, свиток, результаты поиска) — `--text-body`, строки от 56px, measure ≤72ch.
- Числа: `--font-mono` + `--numeric-tnum`. Провенанс и id — всегда mono.
- Импульсы и glow — только по словарю `06-MOTION.md` §5; фейковых сигналов нет.
- Каждый экран несёт: hover/focus/active/disabled/loading/empty/error у интерактивов
  (полные матрицы — `05-COMPONENTS.md`).

## 1. «Обзор» (`/`) — живость памяти

**Задача**: одним взглядом — чем живёт память и что требует владельца. Единственный
экран с правом на hero-момент.

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ ПАМЯТЬ ЖИВА · 12 483 записи · импульсов за час: 37          [Поделиться ▾]   │
│ ┌──────────────────────────────────────────────────────────────────────────┐ │
│ │              CANVAS «колодец» (высота 280px, --color-well-canvas)        │ │
│ │        узлы-воспоминания · миелин-рёбра · импульсы по живой ленте        │ │
│ │   hover узла → спотлайт + тултип «Т-128 · 2 ч · уверенность 0.92»        │ │
│ └──────────────────────────────────────────────────────────────────────────┘ │
│ ┌───────────────┐ ┌───────────────┐ ┌───────────────┐ ┌────────────────────┐ │
│ │ Здоровье      │ │ Счётчики      │ │ Ждут владельца│ │ Сессии агентов     │ │
│ │ хранилища     │ │ 12 483 зап.   │ │ 3 решения     │ │ 1 активная · 2 в   │ │
│ │ ● live · 4/4  │ │ 342 тега …    │ │ [Разобрать]   │ │ очереди [Открыть]  │ │
│ └───────────────┘ └───────────────┘ └───────────────┘ └────────────────────┘ │
│ ┌──────────────────────────────────────────────────────────────────────────┐ │
│ │ Живая лента (последние 8 событий; цвет строки = цвет импульса в канвасе) │ │
│ └──────────────────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────────┘
```

**Ключевые элементы**
- **Canvas-колодец**: 2D без зависимостей; фон `--color-well-canvas` + wash
  `--strata-memory`; узлы = воспоминания (радиус 2–4px по возрасту), рёбра —
  `--synapse-idle` 0.5px; импульс по ребру ТОЛЬКО на событие из ленты
  (recall=ирис, write=золото, error=красный, затухание ≤240ms). Hover-спотлайт:
  подсветка узла + смежных рёбер, остальные притухают до 40%.
- **Живая лента**: строки `--text-data`; каждая строка — цветная точка события
  (дубль импульса в канвасе), текст события, mono-время. Новая строка всплывает
  280ms `--ease-enter`, список ≤8, старое уходит.
- **Bento-блоки** (композиции разные, не плитки): «Здоровье хранилища» (точки
  серверов + подписи), «Счётчики» (tabular-nums, кликабельны в домены),
  «Ждут владельца» (только решения, каждая — действие), «Сессии агентов».

**Состояния**
- Canvas: loading (rAF стартует после first paint; до данных — 3 узла-семени),
  paused (`document.hidden`), reduced-motion (статичная композиция + тинты
  событий вместо импульсов), perf-degraded (если <50fps — узлы до 150, убрать
  glow-спрайты; в консоль стенда — warning).
- Лента: loading (скелетон 3 строк), empty («Пока тихо…»), error (SSE разрыв —
  «Лента отстала. Переподключаемся…» + пилюля топбара жёлтая).
- «Ждут владельца»: empty — «Всё разобрано. Новых решений не требуется.»
- Блоки без содержания не рендерятся (канон против дашификации).

**Микрокопирайт**: CTA «Разобрать решения», «Открыть исполнение», «Все записи →».
Empty-канвас: «Колодец ждёт первую запись. Записать воспоминание».

## 2. «Записи» (`/memory`) — мастер-детейл

**Задача**: масса записей управляется слева, читается справа в свитке.

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ Память / Записи                                   [+] Новая запись  ⌘K      │
│ ┌─────────────── 42% ───────────────┬────────────── 58% ───────────────────┐ │
│ │ фильтры: тег · сервер · тип       │  T-128 «UI-10 проводник»   ●0.92     │ │
│ │ ☑ ┌─────────────────────────────┐ │  провенанс: agb · mnemos-01 · 2 ч    │ │
│ │ ☑ │ T-128  UI-10 проводник      │ │  ┌─────────────────────────────────┐ │ │
│ │   │ ●0.92 #ui #agents  agb·2ч   │ │  │ СВИТОК: Lora 17px, 1.7, ≤72ch   │ │ │
│ │ ☐ │ T-121  пейринг QR           │ │  │ …содержание записи…             │ │ │
│ │   │ ●0.74 #pairing  owner·1д    │ │  └─────────────────────────────────┘ │ │
│ │ …  │ (scroll-restore)            │ │  теги: #ui #agents · [raw ▾] [⋮]    │ │
│ └───┴─────────────────────────────┴──┴──────────────────────────────────────┘ │
│ [bulk-тулбар при выделении: Выбрано 2 · В тег · Удалить · Отмена]            │
└──────────────────────────────────────────────────────────────────────────────┘
```

**Ключевые элементы**
- Список: строка от 56px (`--row-h-airy`), чипы тегов (клик → фильтр),
  confidence-точка золота + число, провенанс «кто·когда» mono `--text-caps`.
- Свиток: `--color-scroll-bg`, `--radius-lg`, Lora `--text-md`, `--leading-relaxed`,
  measure ≤72ch; панель провенанса сверху; теги снизу; «raw ▾» — если
  raw_content отличается.
- Bulk: чекбокс-колонка; при первом `☑` над списком появляется тулбар
  (240ms `--ease-enter`); удаление — confirm-модал с числом.

**Состояния**: список loading (скелетоны 5 строк) / empty («Здесь появятся ваши
записи. Добавить первую» + CTA) / error («Записи не прочитались — сервер ответил
ошибкой» + «Повторить») / свиток пустой выбор («Выберите запись слева — покажем
её целиком») / свиток loading (скелетон абзацев) / 423-lock при правке
(«Запись правит агент agb — подождите или запросите блокировку»).

**Микрокопирайт**: «Новая запись», «Выбрано 2 · Удалить», «Показать полностью».

## 3. «Поиск» (`/memory/search`) — зрачок

**Задача**: полный экран фокуса; вопрос — и глубина отвечает.

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                    (wash --strata-memory, canvas без узлов)                  │
│                                                                              │
│              ⌕  что мы решили про пейринг?_          ← input, radius-xl     │
│              режим: (полный текст) (смысл) (гибрид)   ← сегмент-контрол      │
│                                                                              │
│   ┌ результат 1 ───────────────── всплытие 1 ┐                               │
│   ┌ результат 2 ───────────────── всплытие 2 ┐  stagger 40ms                 │
│   ┌ результат 3 ───────────────── всплытие 3 ┐  hover → спотлайт сниппета   │
│   «Ничего. Смягчите запрос или смените режим на „смысл“.»                  │
└──────────────────────────────────────────────────────────────────────────────┘
```

**Ключевые элементы**
- Input 60% ширины (min 320/max 640), фокус = «зрачок»: border→`--color-iris-bright`
  + `--shadow-iris` + glow-слой ≤0.35 (250ms `--duration-normal`).
- Режимы fts/semantic/hybrid — сегмент-контрол с RU-подписями «полный текст» /
  «смысл» / «гибрид»; активный режим дублируется бейджем на каждом результате.
- Результаты: сниппет 2 строки, highlight-слова — `--color-iris-bright` жирным
  (не цветом одним); hover-спотлайт — карточка приподнимается (`--shadow-raised`),
  соседние приглушаются до 60%.

**Состояния**: idle (подсказки-примеры запросов, кликабельны) / typing (debounce
300ms, не мигаем спиннером на каждый символ) / loading (скелетон 3 карточек) /
results (stagger ≤8, остальные мгновенно) / empty («Ничего не нашлось. Попробуйте
режим „смысл“») / error («Поиск не ответил. Повторить») / partial (hybrid:
«Смысловой индекс неполон — часть памяти ищется только по словам»).

**Микрокопирайт**: placeholder «Спросите память…», примеры: «решение по пейрингу»,
«почему борд заморожен», «теги про агентов».

## 4. «Документы» (`/docs`) — титульные листы

**Задача**: три хаба проектов как книжные титулы, не карточки-плитки.

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ Документы · РУС | ОRIG                                          [Подключить] │
│ ┌────────────────────────────┐ ┌──────────────────┐ ┌──────────────────────┐ │
│ │ mnemos-eyes        [⌗эксп] │ │ gcw              │ │ sealbox              │ │
│ │ ————————— (миелин)         │ │                  │ │                      │ │
│ │ 48 д-ов · обновлён 2 ч     │ │ 112 д-ов …       │ │ 21 д-ов …            │ │
│ │ провенанс: agb · 3 сервера │ │ …                │ │ …                    │ │
│ │ [Открыть хаб →]            │ │ [Открыть хаб →]  │ │ [Открыть хаб →]      │ │
│ └────────────────────────────┘ └──────────────────┘ └──────────────────────┘ │
```

**Ключевые элементы**
- Карточки-«титульные листы»: разная композиция допустима, общее — имя
  (Lora 24px), миелин-разделитель, статистика mono, бейдж провенанса
  («agb · 3 сервера»), билингво-переключатель РУС|ORIG на уровне страницы
  (переключает язык заголовков/сниппетов, не переводит содержимое).
- Первый хаб может быть «шире» (featured) — против одинаковых плиток.

**Состояния**: loading (скелетон 3 листов) / empty («Ни один проект ещё не
подключён. Подключите репозиторий — документы появятся сами» + CTA
«Подключить проект») / error per-хаб («Хаб не ответил — остальные работают») /
хаб-disabled («Проект на паузе — документы в архиве, чтение доступно»).

**Микрокопирайт**: «Подключить проект», «Открыть хаб», «Последнее обновление 2 ч назад».

## 5. «Агенты» (`/agents/execution`) — живое исполнение

**Задача**: очередь и активные assignments; пульс — только реальная активность.

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ Агенты / Исполнение                              [Новое назначение]          │
│ ┌─ АКТИВНЫЕ (1) ───────────────────────────────────────────────────────────┐ │
│ │ ● agb → T-128 «UI-10 проводник»  running · heartbeat 40 c [Открыть]      │ │
│ └──────────────────────────────────────────────────────────────────────────┘ │
│ ┌─ ОЧЕРЕДЬ (2) ────────────────────────────────────────────────────────────┐ │
│ │ ○ core → T-131  в очереди 4 мин · harness: zcode [К началу] [Снять]      │ │
│ └──────────────────────────────────────────────────────────────────────────┘ │
│ ┌─ НИЖНЯЯ ЛЕНТА СОБЫТИЙ (раскрываемая) ────────────────────────────────────┐ │
│ │ 14:02 agb · отчёт (промежуточный) · «волна 1 закрыта»   reported by agb  │ │
└──────────────────────────────────────────────────────────────────────────────┘
```

**Ключевые элементы**
- Агент как узел: точка-статус (running=ирис + пульс только при heartbeat,
  queued=полый контур, failed=красный); heartbeat-возраст mono рядом; >10 мин
  без heartbeat — `--color-warning` + подсказка.
- Честная идентичность: «reported by X (unverified)» — никогда не маскируется
  (ADR 0009 §8).
- Нижняя лента: раскрываемая панель событий исполнения (отчёты, assignment-события),
  состояние раскрытия персистентно.

**Состояния**: loading (скелетон секций) / empty («Назначений нет. Выберите задачу
и назначьте исполнителя» + CTA «К задачам») / очередь stagnant («в очереди 12 мин —
поллер молчит», warning) / failed (терминальный бейдж + tooltip причины) /
error SSE (лента замерла — «События не поступают. Переподключаемся…»).

**Микрокопирайт**: «Новое назначение», «Открыть задачу», «Снять с исполнения»,
heartbeat: «пульс 40 с назад».

## 6. «Рабочий стол» (`/desk`) — доп-слот, OS-метафора

**Задача**: показать, как нейро-стиль живёт в десктоп-метафоре без мишуры.
Бейдж «эксперимент» в сайдбаре и на странице.

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ Рабочий стол ⌗эксперм.                                            [⚙]        │
│ ┌─ окно: Терминал ──────────────────────────── [–] [□] [×] ─┐                │
│ │ mnemos@well:~$ ls projects/                              │                │
│ │ mnemos-eyes/  gcw/  sealbox/                             │                │
│ │ mnemos@well:~$ cat projects/sealbox/README.md            │                │
│ │ # sealbox — …                                            │                │
│ │ mnemos@well:~$ █                                        │                │
│ └──────────────────────────────────────────────────────────┘                │
│ ┌─ окно: Файлы (заготовка) ────────────────────── [–] [□] [×] ─┐             │
│ │ «Проводник ещё собирается. Дерево файлов появится здесь.»   │             │
│ └──────────────────────────────────────────────────────────────┘             │
│ ┌─ ДОК ──────────────────────────────────────────────────────────────────┐   │
│ │ [⌕ поиск] [терминал] [файлы] [память] [агенты]                        │   │
└──────────────────────────────────────────────────────────────────────────────┘
```

**Ключевые элементы**
- Окна: `--color-bg-well`, `--radius-md`, hairline-край + `--shadow-float`;
  фокус окна = `--color-border` край 1px + заголовок `--text-ui` semibold.
  Хоткеи окна: `Ctrl+`` — терминал, `Esc` в окне — не закрывает (защита от
  потери ввода), закрытие — крестик 32px.
- **Терминал**: панель `--color-bg-base` (самая глубокая поверхность в окне —
  «дно колодца на столе»), JetBrains Mono 13px, честная сечатая печать
  (посимвольно 8–16ms/символ — реализм без глянца), команды-моки `ls/cat/cd/help`
  на реальном мини-файл-дереве стенда. Prompt: `mnemos@well:~$`. Ошибка команды —
  красный mono-строкой, не тостом (терминал честен).
- Док: пилюля внизу по центру, иконки 40px, hover — всплытие тултипа; активное
  окно — точка под иконкой.
- Файлы: окно-заготовка с приглашением — масштабируемый слот, честно.

**Состояния**: терминал busy (команда «думает» — курсор мигает, спиннера нет) /
command-not-found (`bash: xyz: команда не найдена; введите help`) / окно empty
(Файлы — приглашение выше) / стол empty («Стол пуст. Откройте терминал —
Ctrl+`») / dock-hover/disabled (слоты будущего — приглушены, tooltip «скоро»,
но не «мертвая» иконка).

**Микрокопирайт**: док-tooltip «Терминал (Ctrl+`)», «Файлы — скоро»; welcome-строка
терминала: «Колодец открыт. Введите help — покажу, что умею».

## 8. «Галерея» (`/gallery`) — дизайн-система

**Задача**: живая витрина канона для владельца и frontend-разработчика.

Секции (вертикальный свиток, якорная навигация слева):
1. **Палитра**: свотчи 5 смысловых + нейтралы; каждая пара подписана расчётным
   контрастом («#E6EDF3 на #0D0F14 — 16.2:1 AA+»); отдельный блок «свет = данные»
   с примерами законного glow.
2. **Типографика**: 2 семейства + mono; микро-шкала caps/data/ui/body рядом с
   замороженной; пример tabular-nums («0123456789» и «счётчик 12 483»).
3. **Плотности**: один и тот же список в compact/comfortable — переключатель
   реально двигает `--row-h`.
4. **Светлая тема**: инлайн-переключатель всей витрины на `[data-theme="light"]`.
5. **State-матрица**: кнопка/чип/карточка/пилюля/поле/термин-строка/узел — все
   состояния в ряд (default…error), включая reduced-motion-сравнение.
6. **Иконография**: lucide-стиль 1.5px stroke, 16/20/24px, запрет-примеры
   (emoji, заливные).
7. **Motion-демо**: кнопка «Проиграть событие» — честный импульс recall/write/error
   по демо-ребру + toggle reduced-motion (см. `06-MOTION.md`).
