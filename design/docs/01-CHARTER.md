# 01 — Устав арт-дирекции: «Живая кора» (vesmaro-eyes v2)

> Status: **v2.0, дизайн-лид, 2026-09-25**. База: design-brief.md («взгляд в себя»),
> design-system.md v1 (teal-ирис, золото-confidence, Inter+Lora+JetBrains Mono),
> концепт IA 2026-09-19 (навигационная модель), дайджест ресерча 2026-09-25.
> Смена направления относительно v1: не «спокойный вьювер» и не «просто утилита» —
> **живой орган**: память как организм с корой, по которой бегут настоящие сигналы.

---

## 1. Направление: «Колодец с живой корой»

Слияние двух ресерч-вариантов в одну метафору:

- **Фосфорный колодец** — глубина и свет. Интерфейс — тёмный колодец памяти;
  свет в нём — **данные, а не декор**: свечением помечено только то, что
  происходит прямо сейчас (активный узел, live-пилюля, фокус). Поверхности —
  charcoal, никогда чистый чёрный.
- **Кора-страты** — скелет. Иерархия интерфейса = слои коры: чем глубже
  поверхность, тем темнее слой; разделы — страты с едва различимыми тинтами;
  связи между элементами — миелиновые волоски 0.5–1px; сигнал — бегущий
  импульс по линии, и **только при реальном событии**.

Формула для команды: **«Кора держит, колодец светит, импульс говорит правду».**

## 2. Принципы (ответ на бриф владельца)

1. **Красиво и уникально** → уникальность строится на трёх структурных вещах,
   а не на раскраске: словарь синапс-импульсов (событие → цвет → место),
   двухуровневая система границ (миелин/функциональный край), RU-лор в копирайте.
2. **Функционально и удобно** → приборная плотность в духе Linear: hairline-границы,
   две плотности (операционная/созерцательная), tabular-nums во всех числах.
3. **Навигация и управление** → доменный сайдбар + крошки + палитра Ctrl+K +
   хоткеи (`/`, `?`, `g`-префикс) — четыре пути к одному действию (распознавание,
   а не припоминание).
4. **Тематика (мозг, память, нейроны)** → лор не наклейка: ирис, страты,
   миелин, импульсы — это **рабочие** элементы интерфейса со своими токенами.
5. **Плавность, скорость, качество** → микровзаимодействия 120–180ms, раскрытия
   240–400ms, ambient «дыхание» 5s с duty cycle ≤20% экрана, canvas 60fps на
   слабом железе. Анимация никогда не стоит между пользователем и данными.
6. **Связность компонентов** → один словарь состояний (state-матрица), одна
   система границ, одна палитра импульсов на всех поверхностях — от дашборда
   до терминала.
7. **Допы (Рабочий стол, Проводник)** → масштабируемые слоты: та же кора и
   те же токены в OS-метафоре, без «скевоморфной мишуры»; в сайдбаре помечены
   бейджем «эксперимент».

## 3. Палитра: 5 смысловых цветов + нейтралы (per-brief обоснование)

| Цвет | Hex (dark) | Роль |
| --- | --- | --- |
| Ирис глубокий | `#1A8A96` | Бренд, графические акценты, solid-заливки. **Не текст** (4.4:1 на well — мало для мелкого текста). |
| Ирис яркий | `#4FC2CE` | Интерактивный текст-акцент, фокус-ринг, импульс recall (≈9:1 на base). |
| Золото confidence | `#C9933A` | Уверенность записи, запись агента, импульс write (≈7:1). |
| Live | `#3FBF7F` | Живое соединение SSE, здоровый heartbeat. |
| Warning / Error | `#D9A03F` / `#E0655C` | Деградация и ошибка; импульс error. |

Нейтралы: лестница коры `#090B0F → #0D0F14 → #12161D → #161B23 → #1C222C`,
текст `#E6EDF3 / #9AA7B4 / #7C8894`.

Статусы — семантическая необходимость (у каждого состояния контракта свой цвет,
дублированный текстом/формой — WCAG 1.4.1), это записанное исключение из лимита
3–5 цветов, унаследованное от v0-концепта §3.5. Золото и warning — близкие
тёплые тона: правило **«не встречаются в одном компоненте»** (confidence-бейдж
никогда не соседствует с warning-бейджем в одном ряду чипов; если домен требует
оба — warning уходит в пилюлю статуса, gold остаётся в контенте).

Шрифты: 2 семейства + mono (Inter, Lora + JetBrains Mono) — канон v1 сохранён.

## 4. Четыре фирменных жеста (где лор работает)

1. **Живость памяти** («Обзор»): canvas-колодец, узлы-воспоминания; импульс по
   ребру — только на реальное событие из живой ленты (recall = ирис, запись
   агента = золото, ошибка = тёплый красный).
2. **Зрачок поиска**: фокус ввода — «фокус зрачка» (ring + glow), результаты
   всплывают из глубины stagger-ом.
3. **Свиток**: содержание записи читается в Lora на поверхности
   `--color-scroll-bg` — «пергамент» внутри коры.
4. **Дыхание**: единственное амбиентное движение — медленный период колодца
   (5s, амплитуда ≤0.06 opacity), никогда под текстом, гаснет при любом
   взаимодействии.

## 5. Анти-клише (блок-лист; нарушение = блокер ревью)

- AI-фиолетово-синие градиенты; любые градиенты как декор (градиентов в системе нет вовсе).
- Фейковые импульсы и «пульсирующие» точки без события; glow на всём подряд.
- Гексагоны, глитч, сканлайны; 3D-мозг-игрушка; био-хоррор-скевоморфизм.
- Чистый `#000` и `#FFF` как поверхности.
- Клон Obsidian: наш граф — дашборд-герой с событийными импульсами, не карта знаний.
- Анимации >400ms на каждый чих; hover-анимация каждой карточки.
- Англицизмы в RU-first копирайте («панель», «палитра», «записи» — не «dashboard», «palette», «entries»).
- Emoji как иконки (иконки — lucide-стиль, 1.5px stroke).
- Eyebrow-капс + «·» + «→» в заголовках карточек; одинаковые карточки-плитки SaaS-китом.

## 7. Самокритика (проход 2; записана до финализации, как требует канон)

**Что здесь по-настоящему наше:**
1. Словарь синапс-импульсов: свечение законно только когда произошло событие,
   цвет импульса кодирует тип события и **дублируется** текстом в ленте. Ни один
   референс (Linear/Obsidian/reflect) не делает событийный импульс словарём системы.
2. Двойная система границ: миелин (декоративный hairline, 7% белизны) vs
   функциональный край (≥3:1, WCAG 1.4.11) — честное разрешение «тонко и красиво»
   vs «видимо и доступно».
3. Страты как модель глубины с тинтами, запрещёнными на текстоносителях —
   атмосфера без ложной семантики.
4. RU-лор в копирайте и aria-атрибутах — язык продукта часть идентичности.

**Что взято у референсов (осознанно, механикой — не видом):** charcoal+hairline
плотность и палитра Ctrl+K — Linear/Raycast; hover-спотлайт графа — Obsidian;
активная мысль в центре — TheBrain; «импорт сигнала с смыслом» — reflect.app;
копирайт «Remember everything» → наш тон «память под рукой, без парадности» — mymind.

**Правки после критики черновика (были бы блокерами):**
- tertiary из ресерча `#6B7885` даёт 3.8–4.2:1 — ниже AA для 11–13px капс-лейблов;
  поднят до `#7C8894` (4.8:1 в худшем случае) — расчёт в `02-TOKENS.md` §4.
- Страт-тинты запрещены на карточках с текстом (только канвас/хиро- wash) — иначе
  они читались бы как статус.
- `--duration-iris` 3000ms → 5000ms (окно ambient 4–6s из ресерча).
- Заголовки свитков остаются на замороженной шкале (32px), а не 30 — новая
  точка шкалы не окупает отдельный токен.

**Проверка «сними бренд»:** без названия продукт опознаётся как «тёмный
приборный кокпит с событийными импульсами и коровыми стратами» — не сводится
ни к Linear (нет их градиентных баннеров и таблиц), ни к Obsidian (граф —
дашборд-виджет с событиями, не карта знаний), ни к generic-дашборду (нет
одинаковых карточек, нет графиков-ради-графиков).
