# 03 — Навигационная модель стенда

> Status: **v2.0, 2026-09-25**. Берёт IA из концепта 2026-09-19 (домены → секции →
> сущности, URL-first) и одевает её в «Живую кору». Стенд — vanilla HTML/CSS/JS,
> все перечисленные хоткеи и палитра **рабочие** (демо-навигация по страницам стенда).

## 1. Карта доменов и секций

```
Обзор            /                        корень, не домен
Память /memory    Записи /memory · Поиск /memory/search · Пульс /memory/pulse · Теги /memory/tags · запись /memory/:id
Задачи /tasks    Канбан /tasks/board · Список /tasks/list · Входящие /tasks/inbox · Архив /tasks/archive · задача /tasks/:id
Агенты /agents   Исполнение /agents/execution · Подключение /agents/harnesses
Документы /docs три хаба проектов
Рабочий стол /desk   Терминал /desk/terminal · Проводник /desk/explorer   [эксперимент]
Настройки /settings  Статус · Настройки · Автоматизация · Устройства · Сессии · Трассировки
Галерея /gallery     дизайн-система стенда                                  [стенд]
```

Правила:
- Вложенность ≤3 уровней (домен → секция → сущность). Глубже — сигнал, что
  сущности нужен свой домен (канон концепта §2.1).
- «Рабочий стол» и «Проводник» помечены бейджем «эксперимент» (тип `--text-caps`,
  золото-dim контур); в стенде кликабельны к мокам.
- «Галерея» — служебная страница стенда, в продуктовой IA не входит; в сайдбаре
  живёт ниже разделителя с бейджем «стенд».

│   Записи ●   │ │                                                           │ │

│   Пульс      │ │                                                           │ │
│   Теги       │ └───────────────────────────────────────────────────────────┘ │

Поверхности: топбар `--color-bg-well` с нижней миелин-линией; сайдбар
`--color-bg-well`; контент `--color-bg-base`. Граница сайдбара —
`--myelin-hairline`; активные элементы получают `--color-border`-качество.

## 3. Сайдбар

- Ширина 232px; сворачивание до 56px icon-only: кнопка-шеврон в подвале сайдбара,
  хоткей `[`; состояние персистентно; подпись бренда скрывается первой.
- Домены — строки 40px (`--row-h` comfortable), иконка lucide 20px + подпись
  `--text-ui`. Секции домена раскрываются под доменом (индев 36px, `--text-sm`).
- Активное состояние: домен — ирис-тинт полосы 2px слева + `--strata-*` wash;
  секция — точка `--synapse-recall` 6px слева + текст `--color-iris-bright`.
- Раскрытие домена: 240ms `--ease-enter`, высота animatable; одновременно
  открыт один домен (предсказуемость, меньше скролла).
- Hover: фон `--myelin-hairline`→`--myelin-strong`; Focus: ринг `--color-focus`
  2px offset 2px (виден на well — 8.6:1).
- Бейджи: «эксперимент» (Рабочий стол), счётчики (Входящие N, Исполнение N) —
  mono `--text-caps`, `--color-text-muted`, never color-only.

Состояния пункта навигации: default / hover / focus-visible / active(текущая) /
disabled (в стенде нет; правило: не прятать, показывать с пояснением) /
collapsed (icon-only, tooltip с полным именем — recognition over recall).

## 4. Топбар

Слева направо: бренд-знак «◉ vesmaro-eyes» (иконка-ирис с микродыханием 5s —
единственное амбиентное движение шелла) · глобальный поиск · spacer · статус-зона.

1. **Глобальный поиск**: ширина 320–480px, placeholder «Поиск по памяти и задачам…»,
   хоткей `/` (фокус), `Esc` — снять. Enter → «Поиск» с текущим запросом.
2. **Live-пилюля SSE**: точка + «live» (`--text-caps`); состояния: live
   (зелёная + `--glow-live`), восстановление (жёлтая, «подключаемся…»),
   разрыв (красная, «нет связи» + кнопка «Переподключить»). Цвет дублируется
   текстом — WCAG 1.4.1.
3. **Счётчик активных исполнений**: «▸2» mono; клик → «Агенты / Исполнение»;
   при running — мягкий пульс точки (только пока есть реальные активные).
4. **Уведомления** (колокольчик, бейдж непрочитанных), **язык RU|EN** (тумблер),
   **тема** (◐ тумблер dark/light).

Мобильный (<768px): бренд-знак и подпись схлопываются в иконку; поиск —
иконка, раскрывается на всю ширину топбара; статус-зона сжимается до live-точки
и счётчика; остальное — в меню «⋮».

## 5. Крошки

- На всех страницах уровня 2–3: `Память / Записи / T-128 «UI-10 проводник»`.
- Последний крамб — не ссылка, `aria-current="page"`. Разделитель «/» —
  `--color-text-muted`. Клик по любому верхнему крамбу — переход (замена
  кнопке «Назад»).
- На сущностях с длинными именами — обрезка по середине (`…`) с полным именем
  в `title`; крошки никогда не переносятся на вторую строку.

## 6. Command palette (Ctrl+K)

Назначение: главный ускоритель «подпрограмм» и прыжков. В стенде — рабочая
демо-версия с навигационными командами и сущностями моков.

- **Открытие**: `Ctrl+K` / `Cmd+K` (независимо от фокуса, кроме полей ввода —
  там `Esc`-очищение, повторный `Ctrl+K` работает), кнопка «⌘K Палитра» в
  сайдбаре, «⌘K» в правом углу крошек.
- **Anatomy**: оверлей (backdrop `rgb(9 11 15 / 0.6)`) + панель 640px
  (`--color-bg-elevated`, `--radius-lg`, `--shadow-modal`), строка ввода с
  placeholder «Куда идём? Попробуйте: „задачи“, „T-128“, „новая задача“»,
  секции результатов: **Переход** (домены/секции), **Действия** (новая задача,
  сменить тему, RU/EN, плотность), **Сущности** (по id: `T-…`, память, агент).
- **Клавиатура**: ↑↓ — перемещение; Enter — выполнить; Esc — закрыть; Tab
  внутри палитры не уходит (фокус-трап); при открытии фокус в строке.
- **Поведение**: поиск по вхождению подстроки + префикс-сортировка; пустой
  результат — не тупик: «Ничего не нашлось по „…“. Запустите поиск по памяти →»
  (кнопка). Выбор — закрытие + toast «Перешли: Записи» (канал обратной связи §6
  ui-contract).
- Состояния: loading (скелетон 2 строк), empty (приглашение выше), error
  («Палитра не получила данные — попробуйте ещё раз» + «Повторить»).

## 7. Хоткеи (все с `inInput`-guard: в полях ввода отключены)

| Клавиши | Действие |
| --- | --- |
| `/` | фокус глобального поиска |
| `Ctrl+K` / `Cmd+K` | палитра |
| `?` | шпаргалка хоткеев (модал с таблицей этой секции) |
| `g` затем `o` / `m` / `t` / `a` / `d` / `w` / `s` | Обзор / Память / Задачи / Агенты / Документы / Рабочий стол / Настройки |
| `g` затем `p` / `b` / `e` | Пульс / Канбан / Исполнение (частые секции) |
| `j` / `k` | вниз/вверх по списку текущей страницы |
| `x` | выделить строку (bulk) |
| `Esc` | закрыть верхний оверлей (палитра → дровер → модал) |
| `[` | свернуть/развернуть сайдбар |

Правила: `g`-префикс живёт 1.5s (индикатор «g→» появляется в крошках);
каждая шпаргалка-модал доступна и мышью (кнопка «⌨» в подвале сайдбара);
никакой моментальной реакции без видимого отклика — действие всегда
подтверждается переходом/состоянием (feedback-канон ui-contract §6).

## 8. Фокус-модель и порядок обхода

- Порядок DOM = порядок Tab: топбар → сайдбар → крошки → контент → подвал.
- Skip-link «К содержимому» первым таб-стопом (WCAG 2.4.1).
- Смена «страницы» (переход по палитре/хоткею) переносит фокус на заголовок
  H1 страницы (`tabindex="-1"`, announce через `aria-live="polite"`).
- Ринги: `--color-focus` 2px + offset 2px; на sticky-элементах (топбар, крошки)
  offset увеличивается до 4px, чтобы ринг не резался контейнером (2.4.11).
- Цели: ≥24×24px везде, 44px на мобильных (2.5.8); иконки-кнопки несут
  `aria-label` RU.
