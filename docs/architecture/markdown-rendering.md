# Markdown-рендеринг: два санкционированных конвейера

**Дата:** 2026-09-23 · **Статус:** Accepted (TL; синк сессий vesmaro-docs ↔ vesmaro-eyes)
**Контекст:** волна UI-27 (TextEngine) и волна 1.27.0 (docs rendering parity, АРХКОМ-8)
независимо построили два react-markdown конвейера. Эта заметка фиксирует границы,
чтобы третьего не появилось, а существующие не разъехались.

## Два конвейера

| Конвейер | Точка | Контент | Особенности |
| --- | --- | --- | --- |
| `features/docs/Markdown.tsx` | docs-хаб (curated corpus) | доверенный, курируемый | heading-slugs, docsAssets, docsLinks, banner — контракт «single react-markdown point» docs-домена (АРХКОМ-8) |
| `components/TextEngine/` | весь остальной интерфейс (авторский текст) | НЕдоверенный (память/задачи/отчёты) | авто-детект markdown, plain-путь бесплатен, lazy-чанк, escape-only (без rehype-raw), clamp |

## Инварианты (оба конвейера)

1. Никакого rehype-raw и dangerouslySetInnerHTML — сырой HTML никогда не рендерится.
2. Только дизайн-токены (text-foreground, border-subtle, bg-elevated) — ноль литеральных цветов.
3. react-markdown + remark-gfm — единственная md-зависимость; новых md-библиотек не заводить.

## Конвергенция (superseded — см. ADR 0020)

> **Superseded (2026-09-24).** Раздел снят с паузы и исполнен
> [ADR 0020](../decisions/0020-unified-text-engine.md): конвергенция
> выполняется по фазам Ф0→Ф3 (Ф0 — золотые фикстуры + браузерный смоук +
> contentClass-гейт; Ф1 — экстракция `text-engine/core`; Ф2 — docs на
> обёртку ядра; Ф3 — уборка дублирования). Двухконвейерный режим ниже —
> **транзитный**: он действует до приземления Ф2/Ф3, правило для новых
> поверхностей сохраняется, триггер касания docs-домена больше не
> применяется (порядок задаёт ADR 0020, старт Ф1+ — после приземления
> активных docs-волн).

TextEngine может делегировать markdown-путь общему базовому рендереру,
выделенному из docs/Markdown.tsx (вторая docs-специфика — slugs/assets/links —
останется инъекцией). Исторический триггер (до ADR 0020): вторая поверхность
с sanitize-потребностью, либо дрейф типографики между конвейерами.

## Правило для новых поверхностей

Авторский текст (память/задачи/отчёты) → TextEngine. Документация →
docs/Markdown. Ничего третьего; сомнение — сюда.
