# ADR 0016: Импорт документации апстрим-проектов в /docs

- Status: **Accepted by committee — pending owner ratification** (АРХКОМ-7, 2026-09-23)
- Deciders: Product Architect, Analytics Lead, Senior System Engineer,
  Docs Writer; вёл `@GCW: Tech Lead`
- Related: ADR 0015 (раздел документации /docs)

## Context

Раздел «Документация» живёт в продукте (ADR 0015): RU-корпус о самом борде,
markdown в бандле UI, без бэкенда. Владелец потребовал расширить его до
полноценных разделов по всем трём проектам семейства — vesmaro-eyes, mnemos,
mnemos-mesh — с тремя жёсткими условиями:

- **Без дрифта.** Контент mnemos/mesh уже написан в их репозиториях; ручное
  копирование устаревает молча, а пересказ своими словами расходится с
  апстримом при каждом его релизе. Нужен парсинг из реп, а не пересказ.
- **Единый стиль.** Читатель не должен чувствовать шов между бордовыми и
  апстримными страницами.
- **Билингво.** Раздел двуязычен (владелец жаловался на смену языка UI);
  импорт не должен ломать это свойство.

Встроенная опасность известна заранее: апстрим живёт своей жизнью, и «всегда
свежая» документация в офлайн-LAN-продукте — обещание, которое нельзя
выполнить бесплатно.

## Decision

Двухслойный импорт «клон → синк → коммит» с хабами проектов и честным
провенансом. Граничное условие комитета: пересказ тел апстрима — другой режим
(ручная документация), несовместимый с целью «без дрифта»; тело
импортированных страниц не редактируется никогда. Условие предъявлено
владельцу на ратификацию вместе с данным ADR.

### 1. Sync-пайплайн, корпус коммитится

`scripts/sync_docs.py` + `scripts/sync-config.yaml` читают локальные клоны
апстримов (`../mnemos`, `../mnemos-mesh`) на **зафиксированном SHA** и по
декларативному конфигу (селекция include/exclude с причинами, инъекция
frontmatter, перезапись относительных ссылок в слаги борда, вырезание
апстрим-хрома, overlay-правила, вендоринг изображений) пишут корпус в
`content/upstream/<project>/<locale>/` + `provenance.json`
(repo/path/SHA/date на каждый файл). Результат коммитится в наш репо с
banner «GENERATED» — офлайн-детерминизм и ревью диффа вместо runtime-фетча.
Тот же синк генерирует статический манифест-сидкар (frontmatter всех страниц
без загрузки чанков) — заодно чинит узкое место первого открытия `/docs`.

### 2. Тело апстрима не редактируется

Единый стиль достигается обвязкой, а не переписыванием: frontmatter,
перезапись ссылок, кураторское интро, словарь соответствий терминов
(страница в glossary, не регэкспы по телу), провенанс-бейдж
«синхронизировано из mnemos@sha · дата». Стилевые правки живут в
overlay-правилах конфига (якорные find/replace); несматчившийся якорь =
fail синка = сигнал дрейфа апстрима. Сгенерированный корпус — read-only для
людей: правка стиля только через конфиг, иначе она умрёт при ре-синке.

### 3. IA — хабы проектов

`/docs/vesmaro-eyes/**`, `/docs/mnemos/**`, `/docs/mnemos-mesh/**`; слаг =
относительный путь (`mnemos/user/getting-started`), группировка сайдбара по
префиксу слага на клиенте, страницы-обложки хабов, breadcrumbs
«Документация → Проект → Категория → страница». Существующие категории
мигрируют в хаб vesmaro-eyes; редирект-мапа старых `/docs/<slug>` сохраняет
закладки и внутренние ссылки. Перекрытия наших и апстримных страниц не
сливаются: субъекты разные (борд vs mnemos-сервер), наши — канон по борду,
между родственными темами — перекрёстные «См. также».

### 4. Селекция, не зеркало

| Источник | Везём | Стр./локаль |
| --- | --- | --- |
| mnemos `user/` | целиком | 10 |
| mnemos `admin/` | выборочно — страницы, на которые смотрят наши runbook-и (security, federation, backup/restore, upgrade) | ~5 |
| mnemos `architecture/` | одна обзорная | 1 |
| mnemos `project/`, `experiments/`, ADR, `sessions/`, ROADMAP, справочники CLI/HTTP API (4000+ строк) | нет — внутренние доки и поверхность разработчика | 0 |
| mesh `en/user` + `en/admin` | целиком (getting-started, configuration, security, runbook) + наш RU-перевод разово | 4 |
| свои 15 страниц | остаются, мигрируют в хаб vesmaro-eyes | 15 |

~16 страниц/локаль mnemos + 4 mesh закрывают пользовательские и операторские
задачи; полное зеркало — мёртвый груз в поиске и налог на каждый синк.

### 5. Билингво

mnemos — обе локали из одного апстрим-коммита (зеркала проверены; расхождение
зеркал — баг апстрима, репортим наверх, у себя не чиним). mesh — EN-оригинал
с честным бейджем «на языке оригинала» до перевода. Свои 15 страниц —
EN-переводы отдельной волной. Непокрытая страница — оригинал с видимым
бейджем; смешивать языки на одной странице запрещено (фолбэк-механика
ADR-0015, молчаливого фолбэка нет).

### 6. Изображения вендорятся

sync копирует изображение-референсы апстрима в `assets/upstream/<project>/`
и переписывает ссылки. Integrity-гейт расширяется на upstream-ассеты: внешних
URL нет, файлы существуют. Правило двухтемности SVG остаётся обязательным
только для наших кураторских схем — апстримные иллюстрации исключение.

### 7. Свежесть — честная

Формулировка «всегда свежая» заменена: «синхронизировано из источника, источник виден
на странице». Синк — ручной, при релизе апстрима (TL или по запросу владельца).
CI-алертов на дрейф не строим — провенанс-бейдж делает дрейф видимым бесплатно.

## Alternatives rejected

- **Git submodules** — worktree-механика: забытый `init` = пустой корпус
  молча; указатели неревьюабельны.
- **Runtime-фетч из сети** — офлайн-LAN исключает сеть на этапе чтения.
- **3-way merge при ре-синке** — недетерминированные конфликты.
- **Автозамена терминов в теле** — ломает код-блоки и убивает доверие к
  синку; термины — словарь-страница.
- **Пересказ тел апстрима «бордовым голосом»** — несовместим с целью «без
  дрифта»; это ручная документация, другой режим.
- **Полное зеркало апстрима (60–80 стр.)** — мёртвый груз в навигации и
  поиске, налог на каждый синк.

## Consequences

- Ре-синк — ручной процесс: обновить SHA в конфиге → `npm run sync-docs` →
  дифф-ревью писаря. `sync-docs --check-drift` показывает расхождение
  зафиксированного SHA с клоном (отчёт, не гейт).
- Гейты ADR-0015 расширяются: перезапись ссылок корпуса верифицируется;
  несматчившийся якорь overlay = fail (DRIFT-гейт); upstream-ассеты без
  внешних URL; `provenance.json` полон; ни одного файла вне include-списка.
- Бюджет: docs-JS ≤120 KiB gzip не меняется (код); upstream-текст — ленивые
  чанки, считается отдельно (аддендум к ADR-0015).
- Гейт «docs обновлены / без влияния на доки» становится критичнее: изменения
  апстрим-контента доходят до читателя только через наш релиз.
- Роллаут волнами W1–W4 (пайплайн → спека хабов → фронтенд → кураторство и
  переводы); состав волн, DoD и риски — в контракте.
