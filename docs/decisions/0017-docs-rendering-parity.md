# ADR 0017: Паритет рендера документации с GitHub — mermaid, ограниченный raw HTML, баннеры

- Status: **Accepted by committee — pending owner ratification** (АРХКОМ-8, 2026-09-23)
- Deciders: Product Architect, Senior Security Engineer, Senior System Engineer;
  вёл `@GCW: Tech Lead`
- Related: ADR 0015 (раздел /docs — бюджетная часть правится этим ADR),
  ADR 0016 (импорт апстрима — его корпус предъявил требования)

## Context

Импорт апстрим-доков (ADR 0016) принёс конструкции, которых рендерер волны-1
не умел: 12 mermaid-фенсов, `<details>/<summary>`, прочий GFM и ведущие
баннеры-комментарии `<!-- ... -->`. Без `rehype-raw` разметка шла сырым текстом,
диаграмма — стеной исходника; гейт «без rehype-raw» защищал бюджет, но лишал
читателя наглядности. Владелец запросил поддержку форматирований.

Рамка решения — **паритет с GitHub-рендером того же файла**: наш рендер не хуже
view на github.com (GFM-таблицы, details/summary, mermaid, task-списки), а не
«полная поддержка всего HTML». Всё остальное — по факту появления в корпусе,
с триггерами возврата, зафиксированными ниже.

## Decision

Восемь пунктов по протоколу АРХКОМ-8; позиции всех трёх — «условно», условия
приняты целиком (ошибку chair в схеме исправил Security — п. 3, бюджетный пробой нашёл SystemEng — п. 6).

### 1. Баннеры-комментарии срезаются

Ведущие цельнострочные `<!-- ... -->`-комментарии (GENERATED/curated) вырезаются
построчно ДО пайплайна; комментарий внутри контента не трогается. Провенанс уже
в бейдже сидкара (ADR 0016) — текстовый дубликат читателю не нужен; санитайзер
комментарии не пропускает и вторым проходом.

### 2. Mermaid — runtime-lazy

`language-mermaid`-фенсы перехватываются до code-блока и рендерятся только через
`Mermaid.tsx`: библиотека приезжает lazy dynamic import'ом при монтировании
первого фенса (vite выделяет её в отдельный чанк; гейт из п. 6 ассертит, что
чанк недостижим статически — ни из `index.html`, ни из eager-цепочки).
Конфиг зафиксирован протоколом, это не тюнинг-кнобы:

| Параметр | Значение |
| --- | --- |
| `securityLevel` | `"strict"` — ЯВНО, не по умолчанию библиотеки |
| `maxTextSize` / `maxEdges` | 20 000 / 200 — гигантские диаграммы не рендерятся |
| Версия | `mermaid@11.17.2`, exact pin (v12 — свежий мажор; пин осознанный) |
| CDN | запрещён — чанк из бандла (`script-src 'self'` и так убьёт CDN) |
| Тема | по `data-theme` (`default`/`dark`), on-line перерисовка через MutationObserver |
| Ссылки в SVG | `<a>` разворачиваются постобработкой — диаграмма не навигирует |

SVG разбирается DOMParser'ом поузлово (никакого `dangerouslySetInnerHTML`).
Фоллбэки: при загрузке чанка и ошибке рендера читатель видит исходник фенса +
предупреждение; сломанная диаграмма — контентный баг, не краш.

### 3. Raw HTML — ограниченно, схема «defaultSchema минус вычтенное»

`rehype-raw` → `rehype-sanitize` в этом порядке, единственное место —
`Markdown.tsx`. Схема (`sanitizeSchema.ts`) строится как **defaultSchema минус
вычтенное**, не ручной allowlist: мини-список молча срезал бы markdown-нативные
элементы (p/таблицы/заголовки), а минус-форма держит GitHub-паритет
(details/summary, kbd/sub/sup, task-списки, footnotes) по построению.

Вычтено/заужено:

- `class` — только на `code`, точная форма `^language-[\w-]+$` (не prefix-match,
  допускающий игры с токенами); фиксированные GFM-классы (task-list, footnote,
  sr-only) остаются — они не attacker-controlled;
- `id`/`name` — запрещены (DOM-clobbering); `style`/`target` не возвращаются
  (в defaultSchema их и не было — запрет зафиксирован на случай возврата
  апстримом); `clobberPrefix` дефолтный `user-content-`;
- `srcset`/`<source>` — вычтены (контрабандный атрибут);
- протоколы: `href` → http/https/mailto (irc/ircs/xmpp вычтены), `src` →
  http/https — относительные проходят, `data:` отсутствует (картинки вендорятся
  пайплайном), внешнее дорежет CSP `img-src 'self' data:`;
- `svg`/`math`/`style`/`iframe`/`object`/`embed`/`form` в tagNames НЕ добавляются;
- `script`: defaultSchema «strip»-ит элемент, оставляя JS-исходник видимым
  текстом, — переведено на drop поддерева целиком (`strip = []`), как GitHub;
  style/iframe дропаются целиком, в allowlist не возвращаются;
- сырой `<input>` defaultSchema превращает в disabled-checkbox — ровно GFM task-list.

Hostile-набор тестов расширен (script/iframe/onerror/javascript:/data:/style/
srcset/svg-use/class-инъекция/гигантская диаграмма) + активные DOM-ассерты.

### 4. Таблицы — CSS-first

Перенос в ячейках — `overflow-wrap: anywhere` на `td`/`th`, не только на `code`:
длинные апстримные идентификаторы не разрывают вёрстку без единой строки JS.

### 5. LaTeX/callouts — отложены

0 использований в корпусе; бюджет отдан mermaid. Триггер возврата: **≥3 блока**
в корпусе — тогда отдельный аддендум с собственной бюджетной поправкой.

### 6. Бюджетная редакция ADR-0015

rehype-raw+sanitize (≈60 KiB) ломали старую планку «docs-JS ≤120 KiB» ещё до
всякого mermaid. Учёт раздельный; гейт — локальный vite-билд в PR:

| Пул | Бюджет | Текущий замер |
| --- | --- | --- |
| Пайплайн рендера (`docs-render-*.js`) | ≤150 KiB gzip (было 120) | 103.2 KiB |
| Mermaid «fence-page»: core + тяжелейшая ветка одного типа диаграмм | ≤450 KiB gzip | 315.6 KiB |
| Полное замыкание всех типов диаграмм разом | info, не гейт | 950.6 KiB |

### 7. Кликабельные ссылки в диаграммах запрещены

Постобработкой SVG (unwrap `<a>` с сохранением подписей). Вердикт по Security
Q2: продукту клики из диаграмм не нужны, надёжнее собственный DOM-проход.

### 8. Governance: allowlist, ESLint-гейт, один PR

- Любое РАСШИРЕНИЕ sanitize-схемы — отдельный PR: обоснование + зелёный
  hostile-набор + обновлённый снапшот схемы. Deny-by-default; расширение
  drive-by коммитом — security-регрессия, а не стилистика.
- ESLint-гейт волны-1 переформулирован: «rehype-raw разрешён только в
  Markdown.tsx; `dangerouslySetInnerHTML` запрещён всюду».
- raw + sanitize + hostile-тесты идут одним PR — атомарно.

## Alternatives rejected

- **«Полная поддержка HTML» без allowlist** — XSS-дыра плюс стилевой разъезд:
  docs выглядят как чужой сайт.
- **Ручная мини-схема sanitize** — срезает markdown-нативные элементы
  (p/таблицы/заголовки), рендер ломается; поэтому вычитание из defaultSchema.
- **mmdc пре-рендер на синке** — puppeteer+chromium на хост синка ради 12
  блоков, двойной рендер тем, шумные SVG-диффы; остаётся задокументированным
  fallback для офлайн-слабых устройств, не основным путём.
- **CDN-импорт mermaid** — убьётся о `script-src 'self'` (и это правильно).
- **LaTeX/callouts сейчас** — 0 использований; бюджет в пользу mermaid.

## Consequences

- Остаточный риск — атрибут `style`: в схему не возвращать без пересмотра CSP
  (его возврат означает `style-src 'unsafe-inline'`) — это отдельное решение
  комитета, не правка схемы.
- mermaid живёт в быстром цикле релизов и имеет XSS-историю 2021–22: пин
  обновляется только через governance-PR (п. 8) с прогнанным hostile-набором.
- Реальный рендер диаграмм юнит-тестами не покрыт (они мокают mermaid) — нужен
  browser-e2e смоук: фенс на странице → `<svg>` в DOM.
- Паритет якорей апстрима (46 якорей) — отдельная волна, вне этого ADR.
- Баннеры уходят из текста без потери провенанса — он в бейдже сидкара (ADR 0016).
