# Группы и канбан-доска

Канбан — главный рабочий стол борда: задачи лежат в колонках и
перетаскиваются мышью. Эта страница объясняет, как доска устроена, как
завести задачу, как работают группы проектов и фильтры — всё, что нужно
для повседневной работы из раздела «Задачи → Канбан».

![Канбан-доска: группы и колонки статусов](screens/kanban.webp)

*Канбан-доска в виде «Группы»: семь колонок — этапы workflow, внутри
каждой карточки собраны по проектам.*

## Как устроена доска

Доска состоит из семи колонок. Колонка — это этап жизни задачи:

| Колонка | Смысл |
| --- | --- |
| бэклог | идеи и заготовки, до работы |
| на валидации | проверка перед взятием в работу |
| открыто | взято в работу, ждёт исполнителя |
| в работе | прямо сейчас делается |
| блокировано | упёрлось во что-то внешнее |
| решено | сделано, ждёт подтверждения |
| готово | финал |

У задачи, кроме колонки, есть статус («открыта», «в работе»,
«заблокирована», «решена», «завершена», «отозвана»), приоритет
(«критический», «высокий», «обычный», «низкий»), проект и теги. Колонки и
статус связаны: колонки «бэклог» и «на валидации» читаются как статус
«открыта».

## Группы проектов

Над доской есть переключатель вида: «Группы» и «Классика».

- «Группы» — внутри каждой колонки карточки собраны в складные группы по
  проектам. Свернули группу — она останется свёрнутой при следующем
  визите. Задачи без проекта всегда в группе «без проекта» внизу.
- «Классика» — сплошные колонки без подгрупп, максимум карточек на экран.

Список задач (раздел «Задачи → Список») группируется по проектам так же —
аккордеонами. Внутри группы задачи идут по приоритету: сначала критические.

## Создайте задачу

1. Нажмите кнопку «Задача» над доской — откроется «Новая задача».
2. Первая строка текста станет названием (до 200 символов), всё
   остальное — сводкой.
3. Укажите проект и при желании теги mnemos через запятую — по ним потом
   удобно искать.
4. Нажмите «Создать задачу». Карточка появится в колонке «открыто».

## Перемещайте карточки

Перетащите карточку в соседнюю колонку — статус задачи изменится, и все
открытые вкладки обновятся сами. Два честных ограничения:

- Без входа перетаскивание выключено — подсказка «войдите для управления»
  (см. [Первый вход для члена семьи](first-login.md)).
- Не всякий переход разрешён: например, из «бэклога» нельзя прыгнуть
  сразу в «решено» — задачу сначала берут в работу. При недопустимом
  переходе карточка вернётся на место с объяснением.

Альтернатива мыши — меню задачи (три точки на карточке): «Изменить»,
«Переместить…», «Архивировать». В списке то же меню открывается правым
кликом по строке.

## Фильтры и поиск

Над доской: поиск по названию или id и фильтры — статус, приоритет,
проект, агент. «Сбросить фильтры» возвращает полный обзор. Под фильтры
попадают и канбан, и список.

## Страница задачи

Клик по карточке открывает страницу задачи с вкладками:

| Вкладка | Что показывает |
| --- | --- |
| Детали | сводка, спецификация, проект, среда, специалисты, теги |
| Отчёты | сообщения агентов по ходу работы, финальный отчёт |
| История | единая хронология: события доски + связанные записи памяти |
| Память | связанные записи из хранилищ mnemos с указанием источника |
| Исполнение | поручения агентам по этой задаче — [Агенты и поручения](agents-assignments.md) |

Две полезные кнопки: «Вернуть в работу» (завершённую задачу снова в
«в работе», колонка не меняется) и «Изменить» — правка контентных полей.

Особый значок «archcom» на карточке означает «требуется решение
владельца». Так же подсвечивается задача, которая висит «в валидации»
дольше 24 часов — доска честно напоминает о застрявших решениях.

## Правка и защита от случайностей

Задача старше 24 часов контентом не редактируется — сервер её бережёт.
Если правка действительно нужна, диалог предложит «Изменить
принудительно»: правка пройдёт и будет помечена в истории как
принудительная.

## Входящие: задачи из памяти

Раздел «Задачи → Входящие» показывает записи `task:queue` из подключённых
хранилищ памяти — задачи, положенные туда агентами или скриптами.

1. Нажмите «Сканировать хранилища» — борд опросит все хранилища.
2. Просмотрите найденные записи и нажмите «Принять в борд» на нужной.
3. Запись станет обычной задачей; ссылка на оригинал сохранится.

## Архив

«Архивировать» в меню задачи убирает её с доски с подтверждением. В
разделе «Задачи → Архив» archived-задачи ищутся поиском и фильтрами,
кнопка «Вернуть на доску» возвращает задачу в игру.
