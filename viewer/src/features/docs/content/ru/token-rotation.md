# Ротация токенов

Ротация — плановая замена токена новым. Делайте её при подозрении на
утечку, после ухода человека, имевшего доступ, и время от времени просто
так — регулярная ротация превращает возможную утечку в нестрашную.
Процедура для каждого класса занимает минуты и не трогает данные.

## Когда ротация нужна

- Есть подозрение, что значение увидело лишнее лицо или попало в лог,
  скриншот, чат.
- Менялся состав людей с доступом к кластеру.
- Плановый срок подошёл (например, раз в полгода) — выберите день и
  пройдите по чек-листу ниже.
- После демонстраций и сессий отладки, где токен мог засветиться.

Общая схема одна и та же: выпустить новое значение → обновить секрет →
перекатить релиз → обновить потребителей. В команде обновления всегда
передавайте `-f my-values.yaml`: helm применит и ваши постоянные
настройки, а не только то, что указано в `--set`.

## Ротация ui-токена

ui-токен вводят люди в окне «Вход», поэтому ротация сводится к смене
секрета.

1. Создайте новое значение и положите его в тот же секрет:

   ```bash
   kubectl -n kube-agents create secret generic vesmaro-eyes-ui-token \
     --from-literal=VESMARO_UI_TOKEN='ui-token-новое-значение' \
     --dry-run=client -o yaml | kubectl apply -f -
   ```

2. Перекатите под, чтобы он прочитал секрет заново (env обновляется
   только при пересоздании пода):

   ```bash
   helm upgrade vesmaro-eyes deploy/chart/vesmaro-eyes -n kube-agents \
     -f my-values.yaml --set image.tag=<текущая версия>
   kubectl -n kube-agents rollout status deployment/vesmaro-eyes
   ```

   Явный `image.tag` обязателен — почему, см.
   [Обновление борда](upgrade.md).

3. Раздайте новое значение тем, кто работает с доской. Старое перестанет
   приниматься сразу, и открытые сессии погаснут: интерфейс покажет
   «Сессия истекла — войдите ещё раз» — нужно вставить актуальное
   значение в окне «Вход».

Если утечка подтверждена, не тяните: старое значение перестаёт работать в
момент переката — предупредите людей заранее, чтобы не застигнуть их
врасплох.

## Ротация machine-токена

machine-токен живёт в поллере на машине с агентами.

1. Смените секрет `vesmaro-eyes-board-token` новым значением — так же,
   как в шагах 1–2 выше (имя секрета то же, ключ `VESMARO_BOARD_TOKEN`).
2. Обновите файл окружения поллера
   (`/etc/vesmaro/poller.env` или переменную user-юнита). Помните права:
   файл должен быть доступен только root (0600).
3. Перезапустите поллер:

   ```bash
   sudo systemctl restart vesmaro-assignment-poller
   # для user-юнита на ноутбуке:
   systemctl --user restart vesmaro-assignment-poller-user
   ```

4. Проверьте лог: `journalctl -u vesmaro-assignment-poller -f` — строка
   старта без ошибок авторизации, поручения забираются.

Поллер переживает короткое окно, когда борд уже на новом токене, а поллер
ещё на старом: попытки авторизации повторяются, ничего не теряется.

## Ротация токена хранилища mnemos

1. На стороне mnemos выпустите новый токен `mnk_…` (с `totp_required=0`)
   и отзовите старый.
2. Обновите секрет `vesmaro-eyes-mnemos` (ключ `MNEMOS_TOKEN`) и
   перекатите борд, как выше.
3. Если подключено LAN-хранилище ноутбука — обновите и его секрет
   (`vesmaro-eyes-laptop`).
4. Проверка: `/api/health` отвечает `ok:true` и видит все хранилища.

## Device-токены

Их не ротируют — их отзывают и выдают заново:

- Отзыв: `DELETE /api/devices/{id}` — мгновенный и необратимый; устройство
  подключается заново пейрингом ([Подключение
  устройства](pairing.md)).
- Без ротации работает и срок жизни: 30 дней скользящих при активности,
  жёсткий потолок 90 дней.

## TLS-сертификат

Сертификат ingress живёт 825 дней; контроль срока —
`./scripts/gen-tls-secret.sh --check`, продление — повторный запуск
скрипта. Перекатывать релиз не нужно: ingress подхватит секрет сам.
Проверьте после продления, что доска открывается без новых
предупреждений.

## Проверка после ротации

- Окно «Вход» принимает новый ui-токен, мутации проходят.
- Поллер в логе стартует без `401`, поручения забираются.
- `/api/health` отвечает `ok:true` — токены хранилищ живы.
- Спаренные устройства (если есть) продолжают читать — их ротация не
  касалась.
